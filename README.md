UDEMY UZ DUB — QISQA QO'LLANMA
Windows + Google Chrome uchun

1. KENGAYTMANI O'RNATING
udemy-uz-dub-0.4.0.zip faylini alohida papkaga oching.
Chrome'da chrome://extensions manziliga kiring.
Developer mode → Load unpacked → ochilgan papkani tanlang.
Papka ichida manifest.json bo'lishi kerak.

2. TARJIMANI SOZLANG
Kengaytma sozlamalarida tarjima xizmatini tanlang.
O'zingizning API kalitingizni kiriting va saqlang.
Modelni tanlab, “Ulanishni sinash”ni bosing.
API xarajati xizmat tarifiga bog'liq. ChatGPT obunasi API kaliti o'rnini bosmaydi.

3. O'ZBEKCHA OVOZNI ISHGA TUSHIRING
Python 3.11+ o'rnating: https://www.python.org/downloads/
O'rnatishda “Add python.exe to PATH”ni belgilang.
edge-tts-helper-0.4.0.zip faylini boshqa papkaga oching.
Ichidagi start-edge-tts.cmd faylini ikki marta bosing.
Birinchi safar paketlar yuklanishini kuting. Internet kerak.
Kompyuter qayta yoqilganda shu faylni yana ishga tushiring.

4. DARSDAN FOYDALANING
Udemy darsida English subtitrini yoqing.
Dub → Tarjima qilish tugmasini bosing.
Ovoz studiyasida Madina yoki Sardorni tanlang — avtomatik saqlanadi.
“Ovozni sinash” bilan tekshiring, keyin darsda dublyajni yoqing.
Ovoz almashtirilsa, dublyajni o'chirib qayta yoqing.

ESLATMA
